# CC0 Tile Lab samples

The rock and vegetation GLBs in this directory are selected from Kenney's
[Nature Kit](https://kenney.nl/assets/nature-kit), version 2.1. They are released under
[Creative Commons Zero (CC0 1.0)](https://creativecommons.org/publicdomain/zero/1.0/).

The original filenames were:

- `rock_largeA.glb`
- `rock_smallB.glb`
- `plant_bushDetailed.glb`
- `plant_flatTall.glb`
- `tree_small.glb`

The original license text is retained in `KENNEY-CC0.txt`. The assets' embedded materials are
replaced at runtime with the PBR materials assigned in Tile Lab.
