# Procedural Texture Lab V0.3.0

## Surface Designer

V0.3.0 promotes the authored surface graph from an inspectable representation to a visual authoring workspace for the V0.3 PTL runtime material model.

Highlights:

- native TypeScript/HTML/SVG graph editor with no React or React Flow dependency;
- draggable nodes with pan, zoom, fit, selection, duplication, deletion, and keyboard controls;
- searchable node browser backed directly by the shared typed node catalog;
- typed input/output sockets and polished Bézier routing;
- solid type-colored graph routes plus dashed legacy runtime field links;
- formal graph routes override the corresponding legacy runtime dependency instead of becoming visual-only wires;
- node parameter inspector with exposed-parameter authoring;
- live compilation through the existing PTL material/runtime path;
- PBR material output routing without a second editor-specific graph model;
- project undo/redo integration;
- touch gesture isolation from the viewport radial menu;
- existing runtime-bound subgraph references remain compatible with shipped and imported graphs;
- arbitrary unbound nested-subgraph creation is deferred until the runtime exposes an executable nested graph interface;
- WebGPU-first material preview remains unchanged beneath the authoring UI.

## Runtime and recipe hardening

V0.3.0 also strengthens the portable graph/runtime boundary:

- graph output source nodes and ports are validated before execution;
- generic graph outputs enforce PBR-compatible types;
- scalar graph outputs may be broadcast to color at the output boundary in imports, mutations, real output-node wires, and the visual editor;
- explicit runtime-bound flagship nodes retain their supported semantic output aliases;
- formal inputs to runtime-bound nodes are lowered into the executable structure/mask dependency slots;
- the two-slot V0.3 runtime dependency limit is enforced, so a third dependency is rejected instead of silently ignored;
- multiple material-output nodes are rejected;
- explicit material-output wires must agree with portable `graph.outputs`;
- stored subgraph output sources are validated recursively;
- graph mutation/runtime-routing tests cover route replacement, cleanup, exposed parameters, executable dependency lowering, and undo integration;
- the full shipped Surface Designer catalog has a compile-contract regression test.

Recipe compatibility remains independent from the npm package version. V0.3 continues to read recipe v1 and v2 and uses recipe v3 for versioned texture-field dependencies.

## PTL Runtime 0.3.0

The reusable runtime package is staged as:

```text
@drusniel/ptl-runtime@0.3.0
```

The package remains WebGPU/TSL first, with the explicit classic `WebGLRenderer` compatibility backend. Three.js stays a peer dependency.

The runtime code and deterministic Lab texture-field assets are licensed under Apache-2.0. The Runtime Package generates deterministic fields when no resolver is installed, so texture-bearing recipes require no external assets. Consumers can still host the higher-fidelity KTX2 catalog and resolve packed channels through `TextureResolver`; this is the recommended production profile.

## Release validation

From a clean checkout of `main`:

```bash
npm ci
npm run release:check
```

`release:check` includes:

1. V0.3 Lab/runtime release metadata consistency;
2. strict unit tests;
3. TypeScript and production Vite build;
4. runtime boundary/config checks and runtime build;
5. browser smoke and renderer fallback smoke;
6. staged npm runtime package validation;
7. clean external TypeScript runtime-consumer test;
8. production export smoke;
9. cross-browser smoke.

CI performs the normal `npm run ci` subset on pushes and pull requests to `main` and supports manual dispatch.

## Manual publishing

GitHub Pages and npm publication remain deliberately separate and manual.

Publish the Lab:

```bash
npm run deploy
```

Publish the runtime:

```bash
npm run publish:runtime
```

Both publish scripts require a clean `main` synchronized with `origin/main`. The runtime publisher also requires npm authentication, reruns CI, performs an npm package dry run, and publishes stable V0.3.0 with the `latest` dist-tag.

## Release boundary

V0.3.0 is feature-frozen around Surface Designer. Larger authoring intelligence features such as reference-image fitting, automatic procedural reconstruction, custom shader nodes, arbitrary nested graph execution, and collaborative graph editing belong after V0.3 rather than expanding this release.
